# TTS and Mic (Beta)

A macOS virtual audio mixer that captures your microphone, mixes in text-to-speech, and routes the combined audio to a virtual loopback device (BlackHole) so other apps can use it as an input source.

Everything is controlled through a web GUI at `http://127.0.0.1:17399`.

## Features

- Capture microphone input and route it to a virtual loopback device (BlackHole 2ch)
- Type text-to-speech that gets mixed into the audio stream in real time
- Monitor the mixed output on your headphones
- Independent volume controls for mic and TTS
- Signal level meters for mic and output
- One-click BlackHole 2ch install via Homebrew

## Requirements

- macOS
- [Homebrew](https://brew.sh) (for automatic BlackHole installation)
- A loopback audio driver ([BlackHole 2ch](https://github.com/ExistentialAudio/BlackHole) or similar)

## Quick Start

```bash
cargo run
```

This starts the app and opens `http://127.0.0.1:17399` in your browser. The terminal shows status messages while the web GUI handles all configuration.

1. Select your microphone (defaults to the system's default input device)
2. Select BlackHole as the output
3. Click **Start Mixer**
4. Type messages in the TTS box and hit **Speak**

## Usage

### Setup screen

- **Input Device** — your microphone (pre-selects the system default)
- **Output Device** — BlackHole 2ch (or any loopback/virtual device)
- **Set as default macOS input** — when checked, other apps will use the mixed audio stream as their input. The original default is restored when you stop.
- **Install BlackHole 2ch** — appears if no loopback device is detected

### Main screen

- **Audio Levels** — VU meters for mic input and mixed output
- **Volume** — independent sliders for mic and TTS (0–200%)
- **Monitor Output** — three modes:
  - **Off** — no monitoring
  - **Monitor** — hear mic + TTS
  - **TTS Only** — hear only TTS
- **Text-to-Speech** — type text and click Speak or press Enter
- **Stop** — stops the audio streams and restores the default input device

All configuration is done through the web GUI.

## How it works

1. Captures audio from the selected input device (your mic) via CoreAudio
2. Stores it in a ring buffer
3. TTS audio is generated by the macOS `say` command and mixed into the buffer
4. The main output stream sends the mixed audio to BlackHole
5. An optional monitor stream plays the mix to your headphones
6. The web server pushes real-time status updates over WebSocket
7. On stop or Ctrl+C, the original macOS default input device is restored
